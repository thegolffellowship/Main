# TGF Insider — voice examples for the writer

This file is fed to the Insider writer (`email_parser/insider_writer.py`)
on every run as "Kerry's sent texts". It holds the PUBLIC Insiders as
Kerry actually sent them, plus one member recap in his own hand for voice.
Add to it only with text Kerry has sent or approved; the lesson list of
record stays in `docs/claude/event-recaps.md` (this file carries texts, not
rules). Every name in a public send is first name + last initial.
